# Bash: файлы, процессы и сеть

Примеры рассчитаны на Fedora и Bash. Имена файлов и устройств заменяйте на свои.

## alias — сокращения в Bash

```bash
alias ll='ls -lhA'   # создать для текущего Bash
alias ll             # посмотреть определение
unalias ll           # убрать из текущего Bash
```

Чтобы сохранить сокращение, добавьте строку `alias …` в `~/.bashrc`.

## Что запускает Bash

```bash
type -a vim          # все варианты команды: алиас, функция, файл в PATH
type z               # проверить функцию в текущем Bash
```

## Копирование, удаление и права

```bash
cp -a project/ backup/       # копировать каталог рекурсивно, сохранив права, владельца и время
cp -i draft.txt dir/         # спросить перед перезаписью (у mv так же: mv -i)
rm -r old/                   # удалить каталог целиком
mkdir -p a/b/c               # создать вложенные каталоги
chmod +x script.sh           # сделать скрипт исполняемым
chmod 600 secret.txt         # читать и писать — только владелец
```

`rm` не спрашивает подтверждения: проверяйте путь перед запуском команды.

## Сравнение файлов

```bash
backup=$(ls -t ~/.bashrc.linux-settings-backup.* | head -1)   # последняя копия
diff -u "$backup" ~/.bashrc
```

Код `1` у `diff` означает, что файлы различаются, а не ошибку.

## ln — ссылки

```bash
ln README.md readme-hard.md       # ещё одно имя того же файла
ln -s README.md readme-link.md    # символическая ссылка на путь
readlink -f readme-link.md        # показать абсолютную цель ссылки
```

Жёсткая ссылка работает в пределах одной файловой системы. Символическая
может указывать на каталог; её относительный путь считается от каталога
самой ссылки.

## dd — поблочное копирование

```bash
image=$(mktemp) && dd if=/dev/zero of="$image" bs=1M count=16 status=progress
```

Пример записывает 16 МиБ нулей во временный файл. `if` — источник, `of` —
назначение. `dd` перезаписывает `of` без подтверждения: проверяйте путь перед
записью, особенно если это устройство в `/dev`. После примера файл можно
удалить командой `rm -- "$image"`.

## Процессы и сигналы

```bash
ps aux | grep -i sshd        # найти процесс по имени
kill 1234                    # SIGTERM: попросить процесс завершиться
kill -KILL 1234              # SIGKILL: принудительно, если SIGTERM не помог
pkill -f long-task.sh        # сигнал всем процессам с такой командной строкой
```

`pkill` без `-f` сравнивает только имя программы (до 15 символов), `-f` — всю
командную строку.

Задачи текущего Bash:

```bash
./long-task.sh &             # запустить в фоне
Ctrl+Z                       # приостановить задачу переднего плана
jobs                         # фоновые и остановленные задачи
bg / fg                      # продолжить в фоне / вернуть на передний план
nohup ./long-task.sh &       # продолжит работу после закрытия терминала
```

## Сеть

```bash
nmcli device status                 # состояние подключений NetworkManager
ip a                                # адреса и состояние интерфейсов
ip r                                # маршруты и шлюз по умолчанию
resolvectl query fedoraproject.org  # проверить разрешение имён
ping -c 3 fedoraproject.org         # проверить доступность узла, три пакета
sudo ss -tulpn                      # слушающие порты; sudo — ради имён процессов
curl -LO https://example.com/file.tar.gz   # скачать файл, следуя перенаправлениям
```
