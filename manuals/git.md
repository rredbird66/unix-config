# Git: ежедневная работа

Примеры рассчитаны на запуск из корня репозитория. Имена файлов и веток
заменяйте на свои.

## Осмотр изменений

```bash
git status -sb                    # краткий статус и текущая ветка
git diff                          # изменения, ещё не добавленные в индекс
git diff --staged                 # что попадёт в следующий коммит
git log --oneline -5              # последние пять коммитов
```

## Подготовка коммита

```bash
git add -p scripts/setup.sh       # выбрать куски изменений по одному
git diff --staged                 # проверить выбранное
git commit -m 'Уточнить меню'     # зафиксировать изменения
```

`git add -p` спрашивает по каждому куску: `y` — добавить, `n` — пропустить,
`s` — разбить на части. Если файл уже добавлен целиком, а в коммит нужна только
часть:

```bash
git restore --staged -- scripts/setup.sh   # убрать из индекса, правки останутся
```

## Если нужно отменить

```bash
git restore scripts/setup.sh      # отбросить незакоммиченные правки файла
```

`git restore` без `--staged` удаляет правки безвозвратно. Для уже
закоммиченного изменения используйте `git revert <коммит>`: он создаёт обратный
коммит, не переписывая историю.
