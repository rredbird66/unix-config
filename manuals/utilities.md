# Терминальные утилиты

Пакеты можно выбрать через `make setup` или установить вместе через `make extras`.
Для `Ctrl+R` и команд `z`/`zi` обновите конфиг командой `make shell` и откройте
новый Bash. Примеры поиска рассчитаны на запуск из корня репозитория.

## tmux — терминальные сессии

```bash
tmux new -s work       # создать сессию work
tmux ls                # список сессий
tmux attach -t work    # вернуться к сессии work
```

Внутри tmux сначала нажмите `Ctrl+B`, отпустите клавиши, затем:

| Клавиша | Действие |
|---|---|
| `d` | Отсоединиться; программы продолжат работать, даже если SSH отключится. |
| `c` / `n` | Создать окно / перейти к следующему окну. |
| `"` / `%` | Разделить окно на верхнюю и нижнюю / левую и правую панели. |
| Стрелки | Перейти в соседнюю панель. |

`exit` закрывает текущую панель; последняя панель завершает сессию.

## SSH и scp — вход и копирование файлов

Возьмите нужный блок `Host` из [ssh/config.example](../ssh/config.example) в
`~/.ssh/config` и замените адрес, пользователя и порт на свои.

```bash
ssh -G targaryen                     # показать итоговые настройки хоста
ssh targaryen                        # подключиться
scp ./README.md targaryen:~/         # отправить файл
scp targaryen:~/README.md ./README.remote.md    # скачать файл
```

Если ключа для этого хоста ещё нет, создайте его по пути `IdentityFile` из
конфига и отправьте публичную часть на сервер:

```bash
mkdir -p -m 700 ~/.ssh
ssh-keygen -t ed25519 -f ~/.ssh/demo-targaryen.key
ssh-copy-id -i ~/.ssh/demo-targaryen.key.pub targaryen
```

Для `ssh-copy-id` нужен действующий способ входа на сервер, например пароль.

## rsync — копирование и синхронизация

В Fedora, если утилита отсутствует: `sudo dnf install rsync`.

```bash
rsync -avh --dry-run ./source/ ./backup/    # посмотреть, что изменится
rsync -avh ./source/ ./backup/              # скопировать локально
rsync -avh ./source/ targaryen:~/backup/     # скопировать по SSH
```

Слеш в конце `source/` означает «копировать содержимое каталога». Для копирования
по SSH `rsync` должен быть установлен на обеих машинах.

## ripgrep (`rg`) — поиск по содержимому

```bash
rg -n 'TODO|FIXME' .                 # совпадения с номерами строк
rg -i 'starship' README.md           # без учёта регистра
rg -l -g '*.sh' 'gsettings' .        # только имена подходящих скриптов
```

По умолчанию при обходе каталогов `rg` пропускает скрытые и игнорируемые файлы.
`-F` ищет буквальный текст вместо регулярного выражения.

## fd-find (`fd`) — поиск по имени

```bash
fd -t f -e md . manuals             # файлы с расширением .md в manuals/
fd -t d '^tests$' .                  # каталоги с точным именем tests
```

`-H` включает скрытые файлы; правила `.gitignore` продолжают действовать.

## fzf — интерактивный выбор

```bash
fd -t f . | fzf                      # выбрать путь из списка файлов
file=$(fd -t f . | fzf) && vim -- "$file"
```

Наберите часть имени, выберите результат стрелками, нажмите Enter; Esc отменяет
выбор. В настроенном Bash `Ctrl+R` ищет по истории и вставляет выбранную команду
в строку ввода.

## zoxide — переход в знакомые каталоги

После настройки Bash `zoxide` запоминает каталог при показе приглашения.
Выполняйте строки примера по одной:

```bash
cd ~/linux-settings
cd ~
z linux-settings    # вернуться по части имени
zi                  # выбрать посещённый каталог через fzf
```

## mc, htop и btop

| Утилита | Основные клавиши |
|---|---|
| `mc` | `F3` просмотр, `F4` правка, `F5` копирование, `F6` перемещение, `F8` удаление, `F10` выход. |
| `htop` | `F3` поиск, `F4` фильтр, `F6` сортировка, `F9` выбор сигнала для процесса, `F10` выход. |
| `btop` | `f` фильтр, `←`/`→` столбец сортировки, `t` отправка `SIGTERM` выбранному процессу с подтверждением, `q` выход. |
