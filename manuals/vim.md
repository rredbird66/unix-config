# Vim: короткая шпаргалка

Открыть файл: `vim README.md`. Vim начинает работу в обычном режиме. Клавиша
`Esc` возвращает в обычный режим из режима ввода или выделения.

## Режимы и движение

| Клавиши | Действие |
|---|---|
| `i` / `a` | Начать ввод перед курсором / после курсора. |
| `A` / `O` | Начать ввод в конце строки / открыть новую строку выше и начать ввод. |
| `o` | Открыть новую строку ниже и начать ввод. |
| `v` / `V` | Выделить символы / целые строки. |
| `h`, `j`, `k`, `l` | Влево, вниз, вверх, вправо. |
| `w` / `b` | К началу следующего / предыдущего слова. |
| `0` / `$` | К началу / концу строки. |
| `gg` / `G` | К первой / последней строке файла. |
| `%` | Перейти к парной скобке для символа под курсором. |
| `:42` + `Enter` | Перейти к строке 42. |

## Правка и поиск

| Клавиши | Действие |
|---|---|
| `x` / `dd` | Удалить символ / строку. |
| `ciw` | Заменить слово под курсором, войдя в режим ввода. |
| `yy` | Скопировать строку в неименованный регистр Vim. |
| `d` / `y` на выделении | Удалить / скопировать выделение. |
| `p` | Вставить удалённое или скопированное после курсора (строки вставляются ниже текущей). |
| `u` / `Ctrl+R` | Отменить / повторить отменённое изменение. |
| `.` | Повторить последнее изменение. |
| `/текст` + `Enter` | Найти текст; `n` — следующее совпадение, `N` — в обратную сторону. |
| `:%s/старое/новое/gc` + `Enter` | Заменить все совпадения в файле с подтверждением каждого. |

Число перед командой задаёт количество: `3dd` удаляет три строки.

## Сохранение и выход

Нажмите `Esc`, введите команду и нажмите `Enter`.

| Команда | Действие |
|---|---|
| `:w` | Сохранить файл. |
| `:q` | Выйти, если нет несохранённых изменений. |
| `:wq` | Сохранить и выйти. |
| `:q!` | Выйти, отбросив несохранённые изменения. |

## Сравнение файлов

```bash
vimdiff vim/vimrc ~/.vimrc     # открыть два файла рядом
```

В режиме сравнения `]c` и `[c` переходят к следующему и предыдущему различию.
`Ctrl+W`, затем `w` — перейти в другое окно; `:qa` — закрыть оба окна после
сохранения изменений.
